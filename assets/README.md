# Visual assets

No reference photographs or generated poster previews are included in this release. This directory documents how to add honest, reproducible visual examples later.

For each published example, include a reference image you have permission to distribute and the resulting poster. Record:

- Source and relevant license or permission.
- Exact prompt and settings, including tool/model version when known.
- Generation date and any manual composition, typography, or upscaling.
- Whether the upper panel uses original pixels or a generative re-render.
- Actual output dimensions and which visual checks were completed.

Suggested filenames: `architecture-reference.jpg` and `architecture-diptych.png`. These names are conventions, not links to bundled files. Keep large originals outside Git when appropriate and use your repository's chosen large-file storage workflow.

Do not label hypothetical examples as completed renders. Keep asset-specific license notices next to the relevant files; the repository's MIT license does not automatically apply to third-party media.
