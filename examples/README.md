# Example prompts

Each file contains a hypothetical reference description, a user-facing Skill invocation, a ready-to-use lower-panel generation prompt, and an assembly note. They demonstrate decisions for different subjects, not just changes in vocabulary.

| Example | Main lesson | Materials |
| --- | --- | --- |
| [Architecture](01-architecture.md) | Preserve a defining void and depth relationship | Cardboard, paper, clay |
| [Portrait](02-portrait.md) | Preserve gesture without toy-like facial styling | Felt, clay, paper |
| [Landscape](03-landscape.md) | Compress depth into a few physical planes | Paper, cardboard, string |
| [Still life](04-still-life.md) | Translate reflectivity into matte color and form | Clay, felt, cardboard |

Use the actual attached image as evidence. Do not claim it contains the objects described here unless it does. All examples default to the preserve route: generate one 4:3 lower panel, then compose a 2:3 poster from two equal-height panels. A one-pass alternative is demonstrated in the landscape file.

No reference photos or generated renders are bundled. The prompts are usable briefs, not a visual benchmark dataset.
